## Reporting Issues

If you find:

* bugs
* broken generation
* balance problems
* crashes
* compatibility issues

please report them through:

* GitHub Issues
* or contact the creator directly

When reporting an issue, try to include:

* screenshots
* game version
* error messages (if any)
* a short description of the problem
