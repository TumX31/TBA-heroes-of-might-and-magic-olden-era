TBA — Heroes of Might and Magic Olden Era Template

Template by TumX

A custom map generation template designed for long-term gameplay with a focus on:

mage-oriented progression
strategic resource management
late-game scaling
extended matches

Current version: V1
This is not the final version. Balance adjustments and improvements are planned for future updates.

Installation

Download the following files:

TBA.png
TBA.rmg.json

Move both files into:

HeroesOldenEra_Data/StreamingAssets/map_templates
Example Path (Linux)
/SteamLibrary/steamapps/common/Heroes of Might and Magic Olden Era/HeroesOldenEra_Data/StreamingAssets/map_templates
Example Path (Windows)
SteamLibrary\steamapps\common\Heroes of Might and Magic Olden Era\HeroesOldenEra_Data\StreamingAssets\map_templates
Important
Do NOT create a separate folder for the template.
TBA.png and TBA.rmg.json must be placed directly inside the map_templates folder.
After installation, the template should appear in the in-game map generator.
About the Template

TBA is focused on:

longer matches
stronger late-game progression
more impactful mage gameplay
strategic macro play
expanded scaling potential

The template is still experimental and may receive:

balance changes
